# 资产库前端

React + TypeScript + Vite，已实现注册登录、项目广场、我的项目、项目创建、协同编辑和 Markdown 详情。

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173。开发服务器将 /api 转发到 127.0.0.1:8888。
首次访问请自行注册。所有页面使用真实后端数据，没有预置账号和假项目。
创建项目可输入 `@姓名` 或 `@用户名` 搜索注册员工并添加共创者；未输入 `@` 时不展示员工名单。共创者登录后可在“我的项目”中查看项目。
项目说明支持“导入 Markdown”：选择本地 UTF-8 编码的 .md / .markdown 文件（含 UTF-8 BOM），最大 200,000 字节，与现有后端说明长度限制一致。
已有说明时确认后才替换；取消或读取失败会保留原内容。导入后可以继续编辑、预览，发布项目时保存正文。
导入不保存原文件为附件，也不会自动上传 Markdown 引用的本地图片；相对图片链接需要后续调整为可访问地址。
此限制仅适用于项目说明文本，不改变项目附件计划的 5 GB 上限。
搜索支持项目名称与简介，列表支持分类、时间排序和分页。
创建项目前会查询同名项目；存在完全同名记录时显示数量并要求确认，用户仍可继续创建。

详情页可进入项目编辑页。所有员工都能编辑名称、分类、简介、Markdown 和演示模块开关；只有作者或管理员能搜索、添加或移除共创者。
详情页提供吸顶内容导航，按“项目说明 / 演示材料 / 项目文件 / 评论 / 编辑历史”定位；未启用演示模块时不显示对应入口。
保存携带当前项目版本号。如果其他员工已先保存，页面保留本地草稿并显示冲突提示，由用户决定何时重新加载最新版。
离开含未保存修改的编辑页时会二次确认，刷新或关闭窗口也会触发浏览器离开提示。文件添加和删除同样属于未保存修改：添加只进入“待保存”，删除只标记“待删除”，点击顶部“保存修改”后才正式执行。文件树中的每个正式文件夹可以单独打包下载，ZIP 保留所选文件夹及其内部目录结构。
创建和编辑表单会把文字字段、分类、演示开关和共创者草稿保存在当前浏览器 7 天；重新进入时由用户选择恢复或删除。项目版本已变化时会提示核对。出于容量与安全考虑，待上传文件不会保存到浏览器草稿，离开后需要重新选择；成功发布或保存后自动清除草稿。

项目详情页支持评论和一级回复。评论列表始终展示，每条评论下的回复默认折叠并可独立展开和收起。全员可以发表；评论和回复均不提供删除操作。评论中输入 `@用户名` 会向已注册员工发送站内提醒；未知用户名、重复提及和提及自己不会生成提醒。
评论加载失败可以重试，登录失效会返回登录页；评论或回复各限 2000 字。

项目详情页的编辑历史默认展示最近一次修改，可展开查看按时间倒序排列的全部记录；每页 20 条，可继续加载更早记录。历史仅供查看，不提供版本恢复操作。

评论和回复输入框支持 @ 提及选择器。输入 `@` 后可按员工姓名或用户名搜索，选择候选人后写入唯一的 `@用户名` 并生成站内提醒；支持方向键、Enter、Tab 和 Esc。

管理员侧边栏提供“员工权限”页面，可为忘记密码的员工生成只显示一次的临时密码。重置会撤销员工已有会话；员工用临时密码登录后只能设置新密码或退出。所有员工也可以从侧边栏“修改密码”。项目作者和管理员可以删除项目，删除前必须输入完整项目名称确认。

项目文件可以在创建时选择；发布后若有待上传文件，会进入编辑页继续上传。详情页只提供文件查看、预览、单个下载和全部下载，添加、续传与删除统一放在“编辑项目”页面。
编辑页使用“项目资料 / 文件与演示 / 协作成员”三个顶部页签；演示模块开关与上传入口位于同一区域，启用后可以立即添加待保存材料。切换页签会保留未保存草稿，并在页签栏持续提示保存状态，文件管理不再位于长表单底部。
支持原格式文件和多文件队列；文件或整个文件夹可直接拖入同一区域，程序自动识别并保留相对目录。文件先暂存于当前编辑页，点击顶部“保存修改”后才按顺序上传；失败或暂停后可再次保存继续，单文件最大 5 GB（十进制）。空文件夹不包含文件，浏览器不会上传。
选择或拖入后，待保存文件会立即出现在同一棵文件树中，并保留原目录层级、标记“待保存”，但此时没有下载入口且其他用户不可见。保存完成后原位置转为正式文件；文件夹内容不会平铺到根目录。
刷新或离开详情会停止传输；重新选择相同文件后可从已有偏移续传。浏览器必须允许本地存储。
文件上传记录按用户、项目和文件指纹隔离。文件指纹使用首尾片段与元数据，不是完整文件哈希。
所有登录员工可以暂存添加或删除项目文件与演示材料；文件树支持删除单个文件，也支持把文件夹中的全部文件递归标记为待删除。保存前可移除待上传文件、撤销单项删除或整体撤销文件夹删除，点击“保存修改”后正式生效。不提供文件替换功能。
项目文件区提供“全部下载”，每个正式文件夹行也提供“下载”；点击文件夹行的“下载”后，后端实时生成保留目录结构的 ZIP，不需要逐个点击，也不会在服务器额外保存一份压缩包。
创建项目时启用演示材料后，详情页会显示“演示材料”区，编辑页提供添加和删除操作。编辑已有项目时，勾选开关会立即显示演示材料区，新增材料只进入“待保存”；顶部保存会先启用模块再上传材料，离开且放弃保存会同时丢弃开关草稿和待上传材料。图片（JPG、PNG、GIF、WebP）、PDF 和 MP4 会在详情页直接展示；PPTX、Word 等其他格式仅显示文件信息。演示材料不提供下载。
文件夹拖入使用 Chromium/Edge 提供的目录读取能力；“添加文件”按钮仍用于普通文件多选。生产构建以 Chromium 69 的语法级别输出，并为内网 HTTP 环境中可能缺失的 AbortController、Clipboard、Web Crypto、Blob.arrayBuffer 和 TextDecoder 提供运行时回退。新增浏览器 API 前必须验证非安全上下文与旧版麒麟浏览器的降级行为。

`npm run build` 执行类型检查并生成 dist。生产部署需要 Nginx 转发 /api，
Vite 的开发代理不包含在 dist 中。不要将开发服务器直接用作公司生产服务。

## 浏览器验收

先启动数据库并应用迁移、启动后端与前端，再运行：

```powershell
npx playwright install chromium
npx playwright test
```

测试覆盖用户名注册、重复用户名、错误密码、管理员重置密码、临时密码强制修改与旧会话撤销、刷新恢复会话、Cookie 属性、跨站拦截、CSRF、非法共创者回滚、项目创建、同名提醒、本地草稿恢复、详情分区导航、Markdown、筛选、协同编辑、只读编辑历史的最新记录与展开交互、共创者权限与归属、回复折叠、评论权限与项目修改时间隔离、管理员和项目删除，以及演示材料隔离与安全预览。
测试创建的 UUID 账号和项目会在 finally 中删除；本地需提供 Docker Compose。
